# Course Overview — VEX Robotics and Computer Vision

## What This Course Is

A hands-on, project-based robotics and computer vision course for high school. Students build real robots, program them, add sensors and autonomy, and then give robots a basic sense of sight using OpenCV. The capstone integrates robotics and vision into one working system.

## Course Philosophy

- **Build first, theory as needed.** Concepts are introduced when students need them to make something work.
- **Phenomenon-driven lessons.** Every lesson starts with a puzzle or demo, a prediction, and a test — then explanation and naming.
- **Iteration is the point.** Robots and vision systems rarely work the first time. Debugging and re-testing are graded skills.
- **Document everything.** Engineering notebooks and portfolios make thinking visible.
- **AI application thinking, not ML math.** Vision is framed as perception that feeds a decision, not as model training.

## Teaching Pattern (used in every lesson)

1. **Phenomenon / Puzzle** — show something surprising or a problem to solve.
2. **Student Prediction** — students commit to a guess.
3. **Conflict / Test Result** — run the test; compare to the prediction.
4. **Explanation** — explain why it happened.
5. **Naming** — attach correct vocabulary.
6. **Transfer** — apply the idea to a new situation.

## Big Ideas Across the Course

- A robot is a system: structure, power, motors, sensors, and code working together.
- Good code is modular, readable, and testable.
- Sensors turn the physical world into data a robot can act on.
- The engineering design cycle turns ideas into tested solutions.
- An image is just numbers; vision is finding meaning in those numbers.
- Perception feeds decisions; every perception system has limits.

## How the Units Connect

```text
Onboarding/Safety
  → Robotics Foundations (build)
    → Programming Motion (control)
      → Sensors & Autonomy (perceive + decide)
        → Engineering Design (solve a challenge)
          → Computer Vision (see)
            → Vision-Based Decisions (see → act)
              → Integrated Final Project
```

## Hardware Flexibility

The course is written to work with **VEX V5** or **VEX IQ**, and with whatever camera you have (USB webcam, V5 Vision Sensor, or VEX AI Vision Sensor). Where exact hardware code differs, lessons use **Python-style pseudocode** so the logic transfers across platforms. Replace pseudocode with your platform's real syntax in VEXcode.

## Time Frame

Designed for a 16-week sequence (see [pacing-guide.md](pacing-guide.md)), roughly one semester with regular lab time. It can be stretched to a full year by deepening projects and adding competition prep.
