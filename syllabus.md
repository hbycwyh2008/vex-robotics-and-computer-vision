# Syllabus — VEX Robotics + Computer Vision

## Course Description

This project-based high school course uses **VEX V5 robotics, the VEX AI Vision Sensor, Python, selected OpenCV, and modern computer-vision theory** to teach perception, autonomous decision-making, engineering iteration, and current AI vision concepts.

Current sequence:

> **VEX AI Vision completed → IBM OpenCV Bridge → Independent VEX Vision Challenge → CS231n Core + Frontier → Final Autonomous Vision Robot**

## Current Starting Point

Completed:
- VEX V5 TrainingBot;
- TrainingBot CAD;
- VEXcode / Python basics;
- official VEX AI Vision Sensor projects.

No mechanical-arm unit is required.

## Learning Outcomes

Students will be able to:
1. use and explain VEX AI Vision outputs;
2. explain image, pixel, channel, threshold, mask, object region and bounding box concepts;
3. connect OpenCV concepts to VEX Color Signature and centerX / centerY / width / height;
4. design an independent visual robot behavior;
5. test robustness and document failures;
6. explain neural-network learning at a conceptual level;
7. explain CNN, convolution, pooling, ResNet and transfer learning;
8. explain object detection, IoU, NMS and YOLO;
9. describe frontier directions including ViT, self-supervised learning, vision-language models and world models;
10. build and defend a final autonomous vision robot.

## Assessment Emphasis

- Engineering evidence / portfolio: 20%
- Formative checks / quizzes: 15%
- Projects and challenges: 40%
- Final integrated project: 20%
- Presentation / reflection: 5%

Frontier topics should normally be assessed through explanation, comparison, discussion, poster, or presentation rather than graduate-level implementation.
