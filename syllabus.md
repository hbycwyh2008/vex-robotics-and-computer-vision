# Syllabus — VEX Robotics and Computer Vision

## Course Description

VEX Robotics and Computer Vision is a project-based course where students build and program real robots, then extend those robots with introductory computer vision. Students move through robot construction, motion programming, sensors and autonomy, the engineering design process, and OpenCV-based perception. The course ends with an integrated project where a robot acts on what a camera sees. Throughout, students document their work in an engineering notebook and a GitHub/Markdown portfolio.

This is a hands-on engineering course. It connects robotics to AI application thinking but is **not** a deep machine learning course.

## Prerequisites

- High school standing (Grade 9+ recommended).
- Comfort with basic problem solving and teamwork.
- Prior programming exposure is helpful but not required.
- No prior robotics experience required.

## Learning Outcomes

Students will be able to:

1. Follow lab safety procedures and work effectively on an engineering team.
2. Build, wire, and maintain a VEX robot.
3. Program robot motion using modular, readable code.
4. Use sensors to enable autonomous robot behavior.
5. Apply the engineering design cycle to solve a robot challenge.
6. Process images with OpenCV (color spaces, thresholding, contours).
7. Connect a vision result to a robot decision and action.
8. Maintain an engineering notebook and a GitHub/Markdown portfolio.
9. Present and defend a final integrated project.

## Classroom Expectations

- Follow all lab safety rules at all times.
- Power down and store equipment properly.
- Document as you go — notebook entries are part of the grade.
- Debug systematically; ask teammates before asking the teacher.
- Use AI tools responsibly and disclose AI assistance honestly.
- Respect shared hardware and clean up your station.

## Portfolio Expectations

Every student maintains a GitHub/Markdown portfolio. See [portfolio-requirements.md](portfolio-requirements.md). Each project must include code, photos/video, an explanation of how it works, what broke and how it was fixed, and a reflection.
