# Lesson Sequence — Anchor Lessons + Daily Teaching Plans

This directory contains the **26 curriculum anchor lessons**. They define the major technical milestones, project context and learning goals.

For direct classroom delivery, do **not** treat these 26 files as the only class periods. The course has 72 guaranteed 90-minute core meetings.

## Teach From Here

1. Start with [`../00-TEACHER-START-HERE.md`](../00-TEACHER-START-HERE.md).
2. Use [`../teacher-notes/core-meeting-playbook/`](../teacher-notes/core-meeting-playbook/README.md) for the daily 90-minute plan.
3. Open the matching anchor lesson below for deeper technical detail.
4. Use [`../student-handouts/project-delivery-pack.md`](../student-handouts/project-delivery-pack.md) for major-project requirements.
5. Use [`../assessments/practical-checkpoints.md`](../assessments/practical-checkpoints.md) for individual mastery checks.

## Shared Learning Flow

> **Learn → Practice → Rebuild → Share**

Robotics applies it through:

> **Predict → Build / Program → Test → Debug → Redesign → Retest → Document → Explain / Transfer**

A robot working once is not mastery. A team result does not automatically prove individual mastery.

## Standard Meeting Architecture

| Time | Function |
|---:|---|
| 0–10 | retrieval / prediction / setup |
| 10–25 | focused learning or demo |
| 25–55 | guided practice → rebuild/application |
| 55–75 | test → debug → redesign → retest |
| 75–85 | evidence / explanation / share |
| 85–90 | individual exit mastery check + reset |

The daily playbook provides the actual prompt/task for each block.
