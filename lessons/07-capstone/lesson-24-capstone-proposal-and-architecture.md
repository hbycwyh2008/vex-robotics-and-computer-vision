# Lesson 24 — Capstone Proposal and System Architecture

## Course position
Week 34 · Integrated Robotics + AI Vision Capstone

## Learning objectives
Students will be able to:
- define a feasible robotics + AI vision problem;
- write measurable requirements and constraints;
- design a system architecture separating perception, decision and action;
- identify required hardware, software and test conditions;
- create a realistic implementation plan.

## Capstone requirement
The final project must integrate:
- a functional VEX robot;
- programmed robot behavior;
- at least one sensor/control component;
- computer vision or AI-vision perception;
- decision logic based on perception;
- measurable testing and documented iteration.

## Example project directions
Teacher approval is required. Possible directions include:
- visually guided target alignment;
- color-object sorting or delivery;
- vision-triggered navigation behavior;
- target tracking with safe motion constraints;
- camera-assisted object interaction;
- a custom challenge that combines perception and mechanisms.

## Part A — Problem statement
Write a concise statement:

> Our system will ___ for ___ under ___ conditions.

Avoid vague goals such as "make an AI robot." The outcome must be observable and testable.

## Part B — Requirements and constraints
Define at least:
- 3 functional requirements;
- 2 reliability/performance requirements;
- 2 physical/hardware constraints;
- 1 safety requirement;
- 1 AI/vision limitation to test deliberately.

## Part C — Architecture
Draw a block diagram containing:
- camera / sensor input;
- perception processing;
- extracted feature(s);
- decision logic;
- robot action;
- feedback / next observation;
- safe stop or fallback path.

## Part D — Test plan
Before building, define how success will be measured.

Possible metrics:
- task success rate;
- detection accuracy;
- alignment error;
- cycle time;
- number of failed detections;
- repeatability across lighting/background conditions.

## Part E — Work plan
Break the project into small milestones:
1. mechanism works;
2. vision works off-robot;
3. decision logic works with test inputs;
4. low-speed integration works;
5. reliability testing;
6. final demonstration.

## Proposal submission
Include:
- project title;
- problem statement;
- requirements/constraints;
- architecture diagram;
- hardware/software list;
- risk/failure analysis;
- test plan;
- team roles;
- milestone schedule.

## Approval criteria
A proposal is approved when the scope is technically feasible within the remaining time and success can be measured objectively.

## AI use
AI may help students brainstorm alternatives, refine wording, identify missing test cases, or critique architecture. Students must make the final design decisions and be able to defend them.
