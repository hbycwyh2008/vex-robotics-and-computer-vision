# Lesson 14 — Manipulator Mechanism Prototype

## Course position
Weeks 20–21 · Engineering Design and Mechanisms

## Learning objectives
Students will be able to:
- translate a task into mechanism requirements;
- compare intake, arm/lift, pusher and gripping concepts;
- sketch a mechanism before building;
- prototype with VEX structure, shafts, gears and motors;
- test function before optimizing appearance.

## Design brief
Create a mechanism that can interact with a teacher-selected lightweight game object or classroom object. The mechanism should complete one clear task such as:
- collect;
- push;
- lift;
- hold;
- release;
- move an object to a target position.

The task should be safe and scaled to classroom hardware.

## Part A — Requirements
Write at least five requirements or constraints. Include:
- object size/shape;
- required motion;
- available mounting space;
- motor quantity;
- speed or force need;
- reliability/safety considerations.

## Part B — Concept sketches
Create at least two mechanism concepts before building.

For each concept identify:
- input motion from the motor;
- transmission method;
- output motion;
- contact point with the object;
- likely failure modes.

Choose one concept and justify the selection.

## Part C — Minimum viable prototype
Build only enough structure to answer the most important unknown first.

Examples:
- Can the roller pull the object in?
- Can the arm lift the object without excessive flex?
- Does the pusher reach far enough?
- Does the gripper maintain contact?

## Part D — Test
Run at least five trials using the same object and start condition.

Record:
- success/failure;
- time or position if useful;
- visible mechanical issue;
- one change to test next.

## Engineering principles
Students should pay attention to:
- rigidity;
- shaft support;
- gear alignment;
- center of mass;
- mechanical interference;
- motor loading;
- repeatability.

## Evidence to submit
- requirements list;
- two concept sketches;
- prototype photos;
- test table;
- decision: continue, revise or replace the concept.

## AI use
AI may suggest mechanism categories or questions to test. Students must verify that any suggested design is compatible with the actual VEX parts and constraints available.

## Next lesson
Use structured iteration: identify the largest performance limitation, make one targeted modification, and measure whether the mechanism actually improves.
