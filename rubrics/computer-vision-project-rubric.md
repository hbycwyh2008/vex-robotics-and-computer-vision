# Computer Vision Project Rubric

| Dimension | 4 — Exceeds | 3 — Meets | 2 — Approaching | 1 — Beginning |
|---|---|---|---|---|
| Pipeline correctness | Complete, well-structured image→mask→detection pipeline | Required pipeline works | Some stages incomplete/unreliable | Pipeline largely nonfunctional |
| Threshold/filter reasoning | Values derived from data and tested across conditions | Values justified and functional | Some guessing / weak justification | Thresholds copied or unexplained |
| Detection quality | Reliable across varied conditions; failures analyzed | Works under required conditions | Inconsistent detection | Frequent false results |
| Measurement | Tracks false positives/negatives or other useful metrics | Uses repeated test evidence | Minimal testing | One-off screenshots only |
| Robustness | Student deliberately stress-tests lighting/background/occlusion | At least one non-ideal condition tested | Limited robustness work | No robustness testing |
| Code clarity | Modular, readable and explained | Understandable code | Some confusing structure | Student cannot explain code |
| AI literacy | Clearly distinguishes raw pixels, rules, decisions and limitations | Explains basic perception limits | Partial understanding | Treats vision output as infallible |

## Evidence expected
- code/notebook;
- input and annotated output images;
- threshold/filter values;
- repeated test matrix;
- false-positive / false-negative discussion;
- limitation and next-step statement.
