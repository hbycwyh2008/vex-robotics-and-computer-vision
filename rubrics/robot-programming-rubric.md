# Robot Programming & Autonomous Control Rubric

| Dimension | 4 — Exceeds | 3 — Meets | 2 — Approaching | 1 — Beginning |
|---|---|---|---|---|
| Correctness | Program reliably performs intended behavior | Required behavior works in normal conditions | Partial/inconsistent behavior | Major functionality missing |
| Code organization | Clear functions/states, readable names, minimal duplication | Code is understandable and reasonably modular | Some repetition/confusing structure | Difficult to follow |
| Configuration | Ports, directions and devices documented and correct | Configuration works | Minor configuration issues | Frequent mismatch between hardware/software |
| Sensor/feedback use | Measurements and feedback are used thoughtfully and robustly | Required sensor/feedback logic works | Sensor logic works inconsistently | Sensor data not meaningfully used |
| Debugging | Systematic layer/state diagnosis with evidence | At least one clear debugging cycle | Mostly trial-and-error | Little diagnostic reasoning |
| Reliability testing | Repeated trials with success/error metrics and improvement | Repeated trials demonstrate performance | Few trials or inconsistent procedure | One-off demo only |
| Explanation | Student can explain every major function/state and design choice | Student explains core logic | Explanation has gaps | Student cannot explain submitted code |

## Evidence expected
- code/repository link;
- device/port map;
- state/flow diagram where relevant;
- repeated trial data;
- debugging evidence;
- AI-use disclosure when applicable.
