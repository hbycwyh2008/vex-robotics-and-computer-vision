# Course Posters

These posters are shared course-culture visuals used across the CS program. They are included in this VEX Robotics repository so the robotics course uses the same classroom learning language and mastery expectations as the Full-Stack Web and AI course.

## Posters used in VEX Robotics

- `classroom-flow.png` — shared classroom learning flow: learn, practice, rebuild, share.
- `mastery-level.png` — shared Mastery Levels 0–5.
- `ai-use-policy.png` — shared responsible AI-use expectations.
- `cs-competition-pathways.png` — optional competition and extension pathways, including robotics and engineering.

## How they apply to VEX

The shared posters establish the common course culture. VEX then applies that culture through an engineering-specific cycle:

> Predict → Build / Program → Test → Debug → Redesign → Retest → Document → Explain / Transfer

The Mastery Level system measures how independently a student can perform, explain, rebuild, debug, modify, and transfer a skill. Project rubrics remain a separate measure of how well a particular engineering project meets its requirements.
