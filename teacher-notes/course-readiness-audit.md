# Course Readiness Audit — Target: 95%+

“95%+ ready” means course-production readiness, not external accreditation.

| Dimension | Weight | 95%+ standard |
|---|---:|---|
| Curriculum coherence | 15% | 36-week sequence, prerequisites, milestones and pacing align |
| Daily teachability | 20% | 90-minute architecture + weekly meeting map + protected lab time |
| Student materials | 15% | notebook, worksheets, project briefs, checklists, portfolio |
| Teacher materials | 15% | demos, preparation, troubleshooting, differentiation |
| Technical resources | 10% | VEXcode/Python patterns + OpenCV starter pipeline |
| Assessment | 10% | formative, practical, projects, capstone, rubrics |
| Operations & safety | 10% | inventory, charging, storage, maintenance, continuity |
| Differentiation | 5% | support, extension, role rotation, absence/hardware-sharing plans |

A 95%+ release has a 2-meeting core plan plus optional third meeting for every week; a defined evidence/assessment endpoint for every unit; teacher preparation and student submission expectations; configuration-aware code examples; explicit debugging and failure procedures; AI disclosure/verification; and calendar buffer capacity.

## Remaining 5% by design

Robotics cannot be 100% pre-scripted because execution depends on school-calendar interruptions, student prior experience, exact kit inventory, VEXcode/firmware versions, hardware breakage, class size, robot-to-student ratio, camera hardware, competition choice and local grading policy. Adapt that final 5% from classroom evidence.
