# Hardware Preparation Checklist — VEX V5 Competition Starter Kit

Use this before the first robotics lesson and again before major build/challenge weeks.

## Per Team
Confirm that each team has access to:
- VEX V5 Competition Starter Kit
- V5 Brain
- V5 Controller
- V5 Robot Battery
- battery charger / charging plan
- required Smart Motors
- sufficient Smart Cables
- structure, shafts, bearings, spacers, shaft collars, gears and wheels needed for the planned build
- correct VEX tools for the fasteners in the kit
- labeled storage bins/trays

## Before Students Arrive
- Charge Robot Batteries.
- Charge Controllers.
- Confirm VEXcode V5 is installed or accessible.
- Update/check VEX firmware if required.
- Verify that each Brain powers on normally.
- Verify that Controllers can pair/connect.
- Test at least one motor and Smart Cable from each kit.
- Photograph the kit/storage layout for reference.
- Prepare labels for team number, Brain, Controller, Battery and storage box.

## TrainingBot Preparation
- Open the official TrainingBot — Competition Kit instructions before class.
- Confirm the instructions match the Competition Kit version.
- Check that high-frequency parts needed early in the build are present.
- Prepare one correctly assembled reference subsystem or teacher demo if useful, but do not pre-build the student robots.

## Tool Control
Keep tools organized and count high-loss items before/after class.

Recommended classroom setup:
- one team tool tray;
- separate location for spare tools;
- labeled T15/T8 or other VEX-specific drivers used by the kit;
- small container for removed screws/nuts during debugging;
- no loose fasteners left on the floor or tables after class.

## Battery and Electrical Safety
- Inspect batteries for visible damage before use.
- Do not use damaged batteries.
- Keep chargers in a supervised, ventilated area.
- Do not modify battery packs or connectors.
- Power the robot down before rewiring motors/sensors.
- Route Smart Cables away from gears, wheels and pinch points.

## Spare / Contingency Items
If available, keep a small teacher reserve of:
- Smart Cables;
- common screws/nuts;
- shaft collars;
- spacers;
- shafts;
- commonly used gears;
- one known-good motor;
- one known-good battery;
- USB/programming cable.

The reserve is for diagnosis and replacement after a fault is identified, not for hiding poor parts management.

## Weekly Maintenance Check
At the end of each week, verify:
- batteries are charging/charged;
- missing tools are located;
- loose hardware is returned to labeled bins;
- robots are powered off;
- damaged components are separated and labeled;
- Brain/Controller/robot are stored with the correct team;
- students have committed or saved code before shutdown.

## Before Computer Vision Weeks
Prepare:
- Python environment;
- OpenCV installation;
- USB webcam or approved camera hardware;
- known test images;
- consistent colored targets/objects;
- simple backgrounds and lighting variations for calibration/testing.

Run the sample camera/OpenCV workflow on the classroom computers before assigning it to students.

## Teacher Diagnostic Rule
When a robot fails, first determine the layer:

**Power → Connection → Configuration → Mechanical → Code → Sensor/Vision → Test Procedure**

Avoid replacing parts or rewriting code until the likely layer has been identified.
