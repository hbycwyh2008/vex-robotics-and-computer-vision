# 36-Week Meeting Map — 90-Minute Regular Course

This file is the year-at-a-glance. For the actual minute-by-minute plans, use [`core-meeting-playbook/`](core-meeting-playbook/README.md).

Each week has **Meeting A** and **Meeting B** as guaranteed core. **Meeting C** is the recommended third meeting when available; otherwise it is extension/buffer/reassessment or rolls forward only when essential. This yields **72 core meetings + up to 36 additional meetings** without overpacking.

## Rules
1. Never consume every Meeting C with new content; preserve buffers.
2. Hardware failure can shift a team to diagnostics, code review, notebook, CV, test planning or practical work.
3. Major projects require repeated trials; one success is insufficient evidence.
4. Ahead teams use the competition extension track rather than dragging the whole class forward.
5. Behind classes reduce challenge complexity before deleting testing/debugging.
6. CV video segments must be followed by local application; do not replace lab time with full Coursera modules.
