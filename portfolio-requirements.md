# Portfolio Requirements

Every student maintains a **GitHub/Markdown portfolio** plus an **engineering notebook**. The portfolio is where you show what you built, how it works, what broke, and what you learned.

## Why a Portfolio

- Makes your engineering thinking visible.
- Builds a real, shareable record of your skills.
- Practices the documentation habits used by real engineering teams.

## Portfolio Structure (suggested)

```text
my-vex-portfolio/
├── README.md                 # About you + project index with links
├── projects/
│   ├── 01-basic-driving-robot/
│   │   ├── README.md         # Explanation, photos, video link, reflection
│   │   └── code/             # Your code or pseudocode
│   ├── 02-sensor-autonomous/
│   ├── 03-robot-challenge/
│   ├── 04-color-detection/
│   ├── 05-vision-decision/
│   └── final-integrated/
└── notebook/                 # Engineering notebook entries (or link)
```

## What Each Project Page Must Include

1. **Overview** — what the project is and the driving question.
2. **How it works** — explain your build and/or code in your own words.
3. **Media** — photos and/or a short video/GIF of the robot or vision output.
4. **Debugging story** — at least one thing that broke and how you fixed it.
5. **Iteration** — what you changed between versions and why.
6. **AI usage disclosure** — if you used AI tools, say how, and confirm you can explain the result.
7. **Reflection** — what you learned and what you'd do next.

## Engineering Notebook Requirements

- Dated entries for each work session.
- Goals for the session and what actually happened.
- Sketches, wiring notes, or screenshots.
- Test results and next steps.
- See [student-handouts/engineering-notebook-guide.md](student-handouts/engineering-notebook-guide.md).

## Markdown and GitHub Expectations

- Use headings, lists, code blocks, and links consistently.
- Commit regularly with clear messages.
- Use relative links between pages.
- Never commit secrets or API keys.
- See [student-handouts/github-markdown-portfolio-guide.md](student-handouts/github-markdown-portfolio-guide.md).

## How the Portfolio Is Graded

The portfolio is graded with the [engineering-notebook-rubric.md](rubrics/engineering-notebook-rubric.md) and contributes to every project grade. Documentation quality, debugging, iteration, and reflection are explicitly assessed.
