# Pacing Guide — 16 Weeks

A suggested one-semester sequence. Adjust to your schedule, hardware, and student pace. Each week assumes regular lab access. Buffer days are built into design and project weeks.

| Week | Unit | Focus | Key Lessons | Deliverable |
|---|---|---|---|---|
| 1 | Unit 00 | Onboarding, safety, GitHub/Markdown notebook | 00-01, 00-02, 00-03 | Portfolio + notebook set up |
| 2 | Unit 01 | VEX components and drivetrain | 01-01, 01-02 | Labeled robot diagram |
| 3 | Unit 01 | Build–test–debug cycle | 01-03 | Working drivetrain build |
| 4 | Unit 02 | Robot motion programming | 02-01, 02-02 | Robot drives a path |
| 5 | Unit 02 | Driver control | 02-03 | **Project 01: Basic Driving Robot** |
| 6 | Unit 03 | Sensor input and decisions | 03-01, 03-02 | Sensor-triggered behavior |
| 7 | Unit 03 | Testing and calibration | 03-03 | **Project 02: Sensor-Based Autonomous Robot** |
| 8 | Unit 04 | Engineering design cycle & strategy | 04-01, 04-02 | Challenge plan + first build |
| 9 | Unit 04 | Iteration and testing log | 04-03 | **Project 03: Robot Challenge Design** |
| 10 | Unit 05 | Images, pixels, color | 05-01 | First OpenCV image script |
| 11 | Unit 05 | HSV thresholding and masks | 05-02 | Color mask demo |
| 12 | Unit 05 | Contours and bounding boxes | 05-03 | **Project 04: Color Object Detection** |
| 13 | Unit 06 | From vision to robot action | 06-01, 06-02 | Vision → decision loop |
| 14 | Unit 06 | Vision system limitations | 06-03 | **Project 05: Vision-Guided Decision System** |
| 15 | Unit 07 | Final project proposal & prototyping | 07-01, 07-02 | Proposal + working prototype |
| 16 | Unit 07 | Final demo and portfolio presentation | 07-03 | **Final Project + Presentation** |

## At-a-Glance Block Summary

- **Week 1:** Onboarding, safety, GitHub/Markdown notebook
- **Weeks 2–3:** VEX components and drivetrain
- **Weeks 4–5:** Robot motion programming
- **Weeks 6–7:** Sensors and autonomous routines
- **Weeks 8–9:** Engineering design challenge
- **Weeks 10–12:** Computer vision foundations with OpenCV
- **Weeks 13–14:** Vision-based robot decision making
- **Weeks 15–16:** Final integrated project, demo, presentation

## Pacing Notes for Teachers

- **If hardware is limited:** rotate teams through build stations; pair vision work (software-only) with build time.
- **If students are new to programming:** spend extra time in Unit 02; keep pseudocode and small functions.
- **If students are advanced:** add competition strategy, multi-object tracking, or PID-style control as stretch goals.
- **Computer vision (Weeks 10–12)** can run partly off-robot on laptops, which helps when robots are shared.
- Keep one buffer/iteration day in Weeks 9, 14, and 15 for testing failures.
