# Advanced Competition Extension Track

This track is for teams that complete core lesson mastery early. It should not replace the core engineering sequence.

## Entry criteria

Students should already demonstrate:
- reliable drivetrain construction and maintenance;
- readable modular robot code;
- controller mapping and autonomous basics;
- engineering notebook evidence;
- disciplined testing rather than random modification.

## Extension A — Driver-control optimization

Investigate:
- nonlinear joystick response;
- acceleration limiting / slew-rate concepts;
- multiple driver profiles;
- mechanism controls mapped to buttons;
- repeatable driver-skills drills.

Students must compare configurations using measured course performance.

## Extension B — Autonomous precision

Explore:
- reusable motion primitives;
- heading correction during straight movement;
- proportional control concepts;
- tuning speed versus overshoot;
- autonomous state machines with timeout/fallback behavior.

Students should graph or tabulate error across repeated trials.

## Extension C — Mechanism optimization

Investigate one mechanism under at least two configurations:
- gear ratio;
- motor placement;
- linkage geometry;
- intake/gripper geometry;
- structural reinforcement.

Evaluate using metrics such as cycle time, success rate, load handled and consistency.

## Extension D — Competition engineering workflow

Teams practice:
1. analyze a game/challenge objective;
2. identify high-value scoring actions;
3. define robot requirements;
4. prototype the riskiest mechanism first;
5. build a minimum viable competition robot;
6. test driver and autonomous performance;
7. prioritize improvements using evidence.

## Extension E — Data-driven strategy

Create a simple match/challenge data sheet. Track:
- successful actions;
- failed actions;
- cycle time;
- autonomous reliability;
- driver errors;
- mechanical failures.

Use the data to choose the next engineering priority.

## Extension F — Vision research challenge

Advanced teams may investigate whether external computer vision improves a specific competition-style task. They must first establish a non-vision baseline and then compare reliability, latency and complexity.

A more complicated AI solution is not automatically a better engineering solution.

## Deliverable

Each advanced extension ends with a short engineering memo containing:
- problem;
- baseline;
- change;
- test procedure;
- results;
- decision;
- next step.
