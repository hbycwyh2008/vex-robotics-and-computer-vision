# Final Assessment — Integrated Robotics + AI Vision Capstone

The final assessment evaluates whether students can integrate mechanical engineering, robot control, visual perception, testing and technical communication into one defensible system.

## Required Components

### 1. Approved Proposal
- problem statement;
- measurable requirements;
- constraints;
- architecture diagram;
- test plan;
- risk/failure analysis.

### 2. Functional Robot System
The project must include:
- VEX robot/mechanism;
- programmed control;
- sensor/control logic;
- computer-vision or AI-vision perception;
- decision logic that uses perception;
- safe fallback/stop behavior.

### 3. Validation Evidence
Students must provide repeated tests rather than one successful demo.

Minimum evidence:
- normal-condition repeated trials;
- at least one stress/non-ideal condition;
- success/failure counts;
- documented failure categories;
- evidence of at least one iteration after testing.

### 4. Engineering Portfolio
Include:
- requirements;
- build photos/diagrams;
- device/port configuration;
- code/repository;
- vision pipeline;
- state/decision logic;
- trial data;
- debugging log;
- limitations;
- AI-use disclosure.

### 5. Demonstration
The demonstration should show:
- perception output;
- decision behavior;
- resulting robot action;
- complete task attempt;
- fallback behavior if practical.

### 6. Engineering Defense
Students answer technical questions about:
- design choices;
- mechanism trade-offs;
- threshold/filter choices;
- state logic;
- reliability data;
- major failure mode;
- AI assistance and verification.

## Suggested Weight Inside Final Assessment
| Component | Weight |
|---|---:|
| Integrated technical system | 35% |
| Testing & validation | 25% |
| Engineering process / iteration | 15% |
| Documentation / portfolio | 15% |
| Presentation & defense | 10% |

## Non-Negotiable Principle
A visually impressive demo cannot compensate for absent evidence. Students must demonstrate that they understand how the system works and what conditions make it fail.
