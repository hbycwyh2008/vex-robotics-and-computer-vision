# Project Assessments

Major performance assessments are distributed across the 36-week course. Each project combines technical performance with engineering evidence.

## Project A — TrainingBot Build & First Drive
**Evidence:** build quality, wiring/port map, pre-power checklist, first-drive demo, debugging entry.

Primary rubric: [Robot Build Rubric](../rubrics/robot-build-rubric.md)

## Project B — Driver Control Challenge
**Evidence:** controller mapping, tank/arcade comparison, repeated challenge data, one evidence-based improvement.

Primary rubric: [Robot Programming Rubric](../rubrics/robot-programming-rubric.md)

## Project C — Autonomous Navigation Challenge
**Evidence:** sensor data, thresholds, state diagram, autonomous code, 10-trial reliability table, failure analysis.

Primary rubric: [Robot Programming Rubric](../rubrics/robot-programming-rubric.md)

## Project D — Competition-Style Robot Challenge
**Evidence:** mechanism design, gear ratio reasoning, scored baseline/final trials, iteration log, engineering defense.

Primary rubric: [Robot Build Rubric](../rubrics/robot-build-rubric.md) + [Presentation Rubric](../rubrics/presentation-rubric.md)

## Project E — Color Object Detection
**Evidence:** OpenCV code, HSV/mask settings, annotated screenshots, repeated condition tests, false-positive/false-negative analysis.

Primary rubric: [Computer Vision Project Rubric](../rubrics/computer-vision-project-rubric.md)

## Project F — Vision-Guided Robot Decision System
**Evidence:** perception/decision/action architecture, decision table, low-speed integration, alignment testing, robustness/fallback tests.

Primary rubrics: [Robot Programming Rubric](../rubrics/robot-programming-rubric.md) + [Computer Vision Project Rubric](../rubrics/computer-vision-project-rubric.md)

## Final — Integrated Robotics + AI Vision Capstone
**Evidence:** proposal, architecture, mechanism, code, vision pipeline, repeated validation, failure testing, engineering notebook, AI disclosure, final presentation.

Primary rubric: [Final Project Rubric](../rubrics/final-project-rubric.md)

## Common Project Requirements
Every major project should include:
1. clear goal/requirements;
2. reproducible setup;
3. code/build evidence;
4. repeated testing;
5. debugging evidence;
6. at least one iteration or justified design decision;
7. limitation statement;
8. AI-use disclosure when applicable.

## Grading Principle
Do not grade only whether the robot worked on the final demonstration. Engineering process, testing quality and the ability to explain the system are core evidence of learning.
