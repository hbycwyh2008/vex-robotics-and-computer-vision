# Final Capstone — Integrated Robotics + AI Vision

## Purpose
Design, build, test and defend an integrated robotic system with meaningful engineering and appropriate sensing/computer vision.

## Required
Defined problem; VEX V5 hardware; purposeful programmed behavior; sensing and/or OpenCV perception; explicit decisions; measurable criteria; repeated validation; documented iteration; demo; technical defense.

## Proposal
Problem; requirements; architecture diagram; hardware/software; risks; test plan; team responsibilities.

## Portfolio
Architecture; build evolution; code structure; test tables; relevant frames; failure analysis; AI disclosure; reflection.

## Individual defense
Each student explains one mechanical decision, one programming/control decision, one perception/sensing decision, one important failure/iteration, and one remaining limitation. A polished demo cannot substitute for understanding.
