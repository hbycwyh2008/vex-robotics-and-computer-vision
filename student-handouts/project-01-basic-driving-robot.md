# Project 01 — Basic Driving Robot

## Goal
Demonstrate reliable programmed movement and explain physical error.

## Requirements
Complete a teacher-defined route with forward motion, a turn and controlled stop. Code must use meaningful variables, at least two reusable functions, correct device configuration and no unexplained copied code.

## Evidence
- port/device map; route diagram; at least 5 measured trials; endpoint/orientation observations; one controlled change + retest; final code; notebook reflection.

## Defense
Explain device configuration, functions, why identical code can produce different physical results, and what changed based on evidence. Disclose meaningful AI assistance and defend all submitted control code.
