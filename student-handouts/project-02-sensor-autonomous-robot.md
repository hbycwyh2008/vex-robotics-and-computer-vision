# Project 02 — Sensor-Based Autonomous Robot

## Goal
Use measurements and decision logic for repeatable autonomous behavior.

## Minimum system
Read at least one environmental/orientation measurement, make a decision from measured state, execute a multi-step autonomous sequence, and include a safe completion/stop state.

## Evidence
Sensor/device map; raw measurements; threshold/target justification; state sequence/pseudocode; **10 validation trials**; success rate; failure classification; one evidence-based iteration.

Do not report “it works” after one success. Explain **measurement → interpretation → decision → motor action → new state** and identify a failure condition.
