# Project 03 — Engineering Robot Challenge

## Goal
Design/improve a mechanism for a competition-style task and justify decisions with data.

## Process
Define task/constraints → baseline → prototype highest-risk mechanism → choose metrics → repeated tests → change one major variable → retest → keep/revert.

Possible metrics: success rate, cycle time, load, reach, driver errors, structural failures, autonomous reliability.

## Evidence
Requirements; labeled sketch/photo; gear/transmission explanation when applicable; baseline + iteration data; final result; failure analysis; notebook/portfolio.

## Defense
Explain why evidence supports the final design over at least one alternative.
